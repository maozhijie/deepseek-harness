# Agent Note：LearnHub 生成上下文注入、节形状门禁与整课重新生成

Status: implemented

[English](2026-09-06-learnhub-generation-context-and-course-reset.md) | 中文

## 问题

生成课程持续超纲，根因在上下文包的前置摘要只写「已生成：讲过（详见其课程文件）」——模型只知道前置节点名字，不知道实际教了什么，于是开方、三角函数随手上场。节内 `###` 子标题与数千字长文没有门禁约束；大纲模型机械地一节内容配一节练习。另外所有生成的交互件在面板必然报错：`extractInteractive` 落盘课程根相对引用（`MathForGames/交互/x.html`），伺服路由却要求 vault 相对（`学习中心/…`）——冒烟测试此前只是因为手写了 vault 相对路径才碰巧通过。重新生成也无法进行：管线断点续跑会跳过已 ready 节与既有题库，不手工清 vault 就点生成等于什么都没发生。

## 决策

教学上下文从「希望模型自己知道」变成数据。`SectionManifest` 保留大纲的 `points`；上下文包前置摘要逐条列出每个已生成前置节点实际教过的节标题+要点（「实际教过的节」），v5 提示词以硬规则引用它：开方/三角/绝对值/对数指数记号只有在前置骨架里出现过的才能直接使用，否则先补一句最小引理或改写为不用该记号的形式。

节形状靠门禁硬约束。质检门新增 `checkSectionShape`：节内 `###` 子标题是 finding（原子性）；prose 过长 warn > 600 / finding > 2000 字（剥离代码块、行内代码、公式与机器注释后计数——公式与图表不占文字预算）。`checkMermaidQuotes` 对未加引号且含 `|` 的 mermaid 节点文本给 warn（渲染降级为源码的高频根因）。大纲提示词明确粒度（一节 = 1–2 屏；需要公式+推导+例题+图才讲完的知识点必须拆节）与组合自由度：练习节可选、连续 2–3 概念节后集中一个练习节、演示穿插均可，唯独不要机械交替。逐节出题量自适应：大纲含练习节时每内容节 1 道，否则 2 道。

整课重新生成成为一等流程。`POST /course/reset`（生成页按钮 + 课程选择 + 破坏性确认）执行 `contentReset`：全部节点笔记逐字节备份进 `.trash/regenerate-<时间戳>/` 后重写为未生成骨架（content=draft、正文清空），三个生成产物目录（`题库/`、`交互/`、`课程图/`）rename 进同一备份；图谱数据、注册表、学习进度、提示词快照、人审的生成队列.md 均不动。路由随后按 `graph.order` 拓扑序在后台串行重跑既有 `generateContent` 管线；单节点失败进任务注册表可重试、不阻塞后续。交互件伺服路由在既有遍历/课程/.html 校验前归一两种引用形态（缺 `学习中心/` 前缀则补上）；质检门的 centerRoot 相对存在性检查语义不变。

提示词 v4 → v5（五个模板；题目生成内容未变保持 v4，避免无谓覆盖用户快照）。

## 后果

重生成不不可逆地删除任何东西（trash rename 可恢复），但掌握度数值会比题目活得久：题库清空后要等后台链跑到该节点才有新题。过期文件按设计被覆盖——v5 升级会把用户手编的提示词快照挪到 `.bak`。形状门禁同样作用于整篇 apply，存量带 `###` 的节在该节点下次重写时会被标出。两个 SDK 不受影响（面板局部缝）。

## 验证

e2e 增至 30 步：形状门禁（`###` 与超长 prose 在 `contentSection` 即拒、合法节过门、mermaid `|` 仅 warn）、大纲 `points` 落盘 frontmatter、`contentReset`（笔记回 draft、`题库/`+`交互/` 移入 `.trash/regenerate-*`、图谱数据完好、旧正文消失）、提示词迁移断言 v5。面板冒烟断言课程根相对交互件路径（截图报错的那种形态）与 vault 相对形态都返回 200。`npm run build`、`npm run check`、UI `tsc --noEmit` 全绿。

## 已否决的替代方案

- **记号级超纲 finding**——符号启发（√、sin…）跨学科误报率高；已教骨架注入 + 提示词硬规则治因而不误伤。
- **题目生成一并 bump v5**——内容没变；强制升版会无故覆盖用户快照。
- **课程重置直接 rm**——仓库已把 `.trash` 作为删除面（`courseDelete` 先例）；rename 进 trash 让重生成可逆。
